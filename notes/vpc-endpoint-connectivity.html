Diagnostic Steps & Root Cause

The root bottleneck typically traces back to one of three isolation layers:

  • Security Group Inbound Primitives: The target VPC endpoint's security group must explicitly allow inbound traffic on the service port (e.g., 443 or database ports) originating from the client microservice's private security group or subnet CIDR block.
  • Subnet Routing & AZ Alignment: Ensuring the client service is residing in an Availability Zone (AZ) that matches one of the subnets the Interface Endpoint was provisioned across.
  • Private DNS Resolution: Verifying if Enable Private DNS Name is toggled on, allowing local service calls to seamlessly override public endpoints without altering codebase configuration strings.
